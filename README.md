## 手機位置自動顯示附近植物

教師後台預設勾選「依手機位置自動顯示附近植物」。按開始定位後，首次可靠定位會直接選取最近的植物；移動後主目標、參考照片與 AI 對話目標一同更新，附近五株按距離排序。定位精度大於 ±25 公尺時暫緩換株；後續換株需有 3–10 公尺的距離優勢（依 GPS 精度調整），減少相鄰樹木與重疊座標間的跳動。

手動搜尋、手動選樹或勾選現場確認後會暫停自動跟隨，固定拍照對象。重新勾選自動跟隨即可恢復，同時清除先前的拍照確認。停止定位或頁面進入背景後不再更新，回到前景須重新開始。位置仍只在目前頁面用於排序，不隨照片或 AI 問答傳送；平台座標仍須現場核對，不代表能以手機 GPS 識別單株。

## 校園空間定位拍照與四向實景

校園空間的 3D 視角與導覽頁提供「空間定位拍照」入口，使用原有指定管理員登入及 GitHub 上傳服務。`field.html?mode=space` 是空間拍照畫面，`tour.html?mode=simple` 是四向實景導覽。每個 P01–P18 站點需前方、右方、後方、左方四張水平照片（以本站第一張朝向為前方，補拍沿用同一基準），共 72 張；手機橫放，在同一位置以眼睛高度轉身拍攝，不需天空或腳下。照片可左右滑動、按方向或方向鍵切換，缺少的方向顯示待拍；這是分方向實景展示，沒有自動拼接、立體深度或照片重建模型。

既有俯視圖標點沒有 GPS，首次需現場選站。取得 20 秒內、誤差不大於 25 公尺的定位並確認後，本站四張照片共用固定座標，上傳時明示連同站點 GPS 公開。無可靠定位時仍可手動選站拍攝，不附上推估座標。已保存／發布的實際站點 GPS 才參與最近站點排序；定位與植物相同使用距離優勢防止跳動。頁面進入背景會停止定位，拍下一站前應重新取得定位。

拍照進度分為未拍、已存本機、GitHub 已接收、已在網站發布；「重新確認發布進度」讀取實際部署後的清單。拍攝鎖定站點後才開相機，保存時保留站點、方向及同次確認的 GPS，防止換站誤配。植物現場照片在公開清單確認發布後，該株的 Wiki 搜尋及參考圖停止顯示，保留清冊編號／GPS／碳資料；同樹種共用圖檔仍供尚未完成實拍的其他植株使用。

## 定位地圖放大與站點朗讀

植物定位圖背景透明度調整為 40%，點選地圖可放大查看，手機可捲動，關閉按鈕或 Escape 返回；放大時保留同一張即時定位圖。底圖仍未與 GPS 精準對位。

空間拍照的「朗讀目前站點」會停止原有朗讀與定位監看，重新取得一次最新 GPS，再比對已有可靠座標的站點。定位精度需在 ±25 公尺內、資料在 20 秒內且距最近站點不超過 30 公尺，才切換至該站並朗讀；不依預選站點猜測所在位置。權限拒絕、精度不足、遠離站點或沒有站點座標時只顯示原因；停止朗讀、換站、背景化或登出後，遲到的定位回覆不會觸發朗讀。定位結果仍須現場核對；朗讀不代表確認拍攝位置。

鳥類觀察新增帶全螢幕圖示的「全螢幕大南國小鳥鳴練習」按鈕，另開指定題庫並帶入 `fullscreen=1&play=audio`，進入滿版字卡與純鳥鳴循環；若瀏覽器攔截自動播放，需在鳥鳴頁再按「只朗讀鳥鳴」。

鳥類觀察的麻雀／白頭翁採用經使用者確認的透明去背版本，分別固定在 B01／B02 圖片標記旁，只做原位微幅擺動；縮放與手動標點後跟隨同一圖片座標，暫停時保留鳥隻。只在鳥類圖片視角顯示，減少動態偏好時保持靜止。去背圖片由 ImageGen 處理，原始參考照片保留，來源與衍生檔資訊列於 `dist/bird-reference.json`；非季節分布或目擊紀錄。

## 透明背景鳥類循環影片

B01 麻雀與 B02 白頭翁使用 15 秒透明背景 WebM，在固定標記旁播放鳥本身的動作。暫停動畫、切換主題、背景分頁及系統減少動態設定均會停止自動播放；影片無法讀取時保留去背照片。影片由 AI 合成，並非現地目擊或真實野外行為紀錄。校方照片參考保留原照片及來源，已核對鳥種另附可手動播放的動畫；第二張角鴞照片仍保留鳥種待核對狀態，不用未確定身份的照片生成動畫。
