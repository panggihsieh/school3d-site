# 校園地圖 v3 獨立圖層

底圖：使用者兩張空拍照片所重繪 v3，再移除文字。生成原圖保留於本機 generated_images 與 output 草稿。正式檔 dist/assets/campus-base-v3-20261111.png。

區域：dist/campus-regions.json，依 2026/11/09 校方校對圖概略配置；北朝左下前門。18 個文字名稱獨立於底圖，非測繪、地籍或正式避難動線。

教師後台登入後，工作區最上方可修改名稱、拖曳、輸入百分比微調、保存本機草稿及發布。發布須指定 Google 管理員驗證，GitHub 使用非強制提交及前版比對，版本時間隨發布更新；前台讀同一份 JSON 疊圖。原有照片 ID、方向及 GPS 不變。舊底圖植物手動標點保留原 localStorage，使用新鍵避免錯位沿用。
